## 2025-02-28 - Timing Attack Vulnerability in API Key Validation
**Vulnerability:** Comparing internal API keys using strict string equality (`===`) in `src/app/api/admin/storage-check/route.ts` makes the application susceptible to timing attacks, allowing attackers to guess the key character by character by measuring the time it takes for the comparison to fail.
**Learning:** Hardcoded string equality operators exit early on the first mismatched character. This slight time variance can be measured and exploited to extract secrets, bypassing authentication mechanisms. Using a secure comparison function prevents this type of attack. Empty string fallbacks (`|| ""`) for both provided and expected keys can result in a dangerous authentication bypass.
**Prevention:** Always use `crypto.timingSafeEqual(Buffer.from(provided), Buffer.from(expected))` to compare sensitive strings like API keys or tokens. Ensure both values are valid strings (and check for truthy values), convert them to `Buffer` objects, and verify that their byte lengths match (`buf1.length === buf2.length`) before calling the timing-safe function to prevent `RangeError` with multi-byte characters.
