## 2024-03-24 - [Timing Attack Risk on Internal API Key Comparison]
**Vulnerability:** The internal API key in `src/app/api/admin/storage-check/route.ts` was being compared using the strict equality operator (`===`). This allows an attacker to perform a timing attack by measuring the time it takes for the server to respond. If the server rejects the key quickly, the attacker knows the first character is wrong. If it takes slightly longer, they know the first character is right but the second is wrong, allowing them to guess the key character by character.
**Learning:** Using standard string comparison for security-sensitive tokens and passwords leaks length and character matches over time.
**Prevention:** Always use constant-time comparison functions like `crypto.timingSafeEqual`. When using it, ensure both inputs are converted to `Buffer`s, check their byte lengths first (`buf1.length === buf2.length`) to prevent `RangeError`s with multi-byte characters, and handle null/empty strings correctly to avoid authentication bypasses if the environment variable is missing.
