## 2025-02-14 - Fix Timing Attack in Internal API Key Verification
**Vulnerability:** The internal API key in `src/app/api/admin/storage-check/route.ts` was being validated using strict string equality (`===`). This allows an attacker to perform a timing attack by measuring the time taken for the comparison to fail, deducing the key character by character.
**Learning:** Even internal API routes and simple scripts should utilize constant-time comparison methods for secrets to follow a defense-in-depth security approach. Node's `crypto.timingSafeEqual` throws a `RangeError` if the buffers have different lengths, so checking `buffer.length` prior to the call is crucial to avoid crashing the application on invalid requests.
**Prevention:** Always use `crypto.timingSafeEqual` (or an equivalent secure string comparison library) for validating passwords, tokens, API keys, or HMAC signatures. Ensure inputs are converted to Buffers, lengths are checked, and neither input is an empty string.
