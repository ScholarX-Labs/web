## 2024-09-06 - Timing Attack Vulnerability in API Key Comparison
**Vulnerability:** The internal API endpoint `src/app/api/admin/storage-check/route.ts` used a strict equality operator (`===`) to compare the provided `x-internal-key` header against the expected `INTERNAL_API_KEY` environment variable. This is vulnerable to timing attacks where an attacker can theoretically deduce the correct key character by character based on how long the comparison takes.
**Learning:** Security-sensitive strings, particularly API keys and tokens, should never be compared using basic string equality. It's crucial to evaluate byte arrays in constant time.
**Prevention:** Use `node:crypto`'s `timingSafeEqual(Buffer, Buffer)` for all sensitive string comparisons. Always ensure inputs are checked for byte-length equality before performing `timingSafeEqual` to avoid a `RangeError`, and ensure neither the provided nor expected key falls back to an empty string to prevent authentication bypasses.
