## 2024-03-24 - [Timing Attack in API Key Comparison]
**Vulnerability:** A strict string equality (`===`) check was being used in an API route (`/api/admin/storage-check`) to compare an internal API key against a provided header (`x-internal-key`). This exposes the endpoint to a timing attack where an attacker can determine the key based on how long the comparison takes. Additionally, if the environment variable (`INTERNAL_API_KEY`) is missing, falling back to an empty string comparison could lead to an authentication bypass.
**Learning:** Security checks that compare secrets, especially API keys or passwords, must be done in constant time to prevent timing attacks. Empty string fallbacks for missing environment variables are dangerous and can be exploited.
**Prevention:** Always use `crypto.timingSafeEqual` to compare secrets. Ensure the variables are converted to Buffers, and the buffer lengths are checked before comparison. Explicitly handle cases where environment variables might be missing by defaulting to a failing comparison, rather than an empty string check.
