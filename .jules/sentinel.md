## 2024-05-24 - Timing attack vulnerability on internal API endpoint
**Vulnerability:** A timing attack vulnerability was identified in `src/app/api/admin/storage-check/route.ts` because it used strict equality (`===`) to compare `process.env.INTERNAL_API_KEY` against the `x-internal-key` header. This allows attackers to potentially guess the secret by measuring the time it takes for the application to respond.
**Learning:** Comparing secrets using string equality operators (`===` or `==`) is a common anti-pattern that exposes the application to timing attacks, as string comparisons short-circuit upon the first mismatched character.
**Prevention:** When comparing sensitive strings such as API keys, tokens, or passwords, always use `crypto.timingSafeEqual` in Node.js (or equivalent constant-time comparison functions). Ensure inputs are converted to Buffers, checking their byte lengths before comparison to prevent `RangeError` on mismatched lengths and to handle multi-byte characters safely.
