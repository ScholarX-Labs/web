## 2024-07-28 - Timing Attack Vulnerability on Internal API Key
**Vulnerability:** The internal API endpoint `src/app/api/admin/storage-check/route.ts` used a strict equality operator (`===`) to compare the `x-internal-key` header with `process.env.INTERNAL_API_KEY`. This is susceptible to timing attacks, allowing an attacker to guess the secret key by measuring the response time.
**Learning:** String comparisons of secrets using `===` in V8/Node.js exit early on the first mismatched character. This minute timing difference can be exploited over thousands of requests to reconstruct the expected string. Additionally, fallback mechanisms must be carefully handled so that an undefined environment variable and an absent header do not accidentally evaluate to `true`.
**Prevention:** Always use `crypto.timingSafeEqual(buf1, buf2)` for comparing secrets. Convert strings to Buffers first and ensure their lengths are identical (`buf1.length === buf2.length`) before calling `timingSafeEqual`, as it throws a `RangeError` if lengths differ. Also, ensure neither value is undefined or falsy before comparison.
